### 要求

- 至少 2 个指标
- 指标必须可量化、可计算
- 禁止模糊词：「高效」「稳定」「良好」「显著提升」「尽量」
- 目标值用户未提供时填 `[待补充：{指标名}的目标值]`
- 定义与公式不得为空，不得写「同上」

## 3. 三层指标分层（通用）

讨论衡量方式时，按下表分层锁定。缺失层不强加，但每层必须显式确认「有 / 无」。

| 层级 | 作用 | 数量 | 典型口径 |
| :--- | :--- | :--- | :--- |
| **北极星** | 这件事做完最关心的**一个**数字 | 1 | 人工介入率、任务成功率、报表耗时、自愈率 |
| **辅助** | 从不同角度确认效果 | 1–2 | 人均处理时长、人均浏览深度、复用率、覆盖对象数 |
| **护栏** | 做完后**不能恶化**的指标 | 0–1 | 误报率、系统可用性、成本、安全事件数、留存率 |

**常见收敛示例**（仅说明收敛方式，生成真实 PRD 时禁止照抄）：

| 用户说的 | 收敛后的北极星指标 |
| :--- | :--- |
| 「运营效率提升」 | 运营每天花在报表上的时间 |
| 「推荐更准」 | 推荐内容点击率 |
| 「系统更稳」 | 消息发送成功率 |
| 「用户不迷路」 | 设置项完成率 |

## 4. 归属与用法

| 方向 | 使用位置 | 采用版本 |
| :--- | :--- | :--- |
| S · 通用软件 | 阶段二 概念版 PRD（对齐稿） | 轻量版（§2） |
| S · 通用软件 | **补充说明 §2.3 需求目标与成功标准** | 完整版（§1）+ 分层（§3） |
| A · Agent 类 | 阶段二 概念版 PRD（对齐稿） | 轻量版（§2） |
| A · Agent 类 | **补充说明 §2.3 需求目标与成功标准** | 完整版（§1）+ 分层（§3），另加数据来源与观察周期 |
| A · Agent 类 | 正文第四章「指标与可观测性 → 技术指标」 | 仅运行期技术指标，不含业务指标目标值 |

> **归属提示**：业务指标（含定义、计算公式、目标值、观察周期）属「需求背景」类，登记于**补充说明**，不写入正文；正文只承载运行期技术指标与可观测性要求（响应时间、吞吐、资源、日志、自监控）。
