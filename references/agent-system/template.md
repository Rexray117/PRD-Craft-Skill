**正文净化约束（强制）**

(1) 本模板为**正文**。首行为文档标题，其后直接进入第一章，**不写元信息行**。

(2) 正文**不得出现**：版本号、日期、作者、名词解释、角色与读者、需求背景、痛点、目标用户、需求目标、成功标准、待确认清单、篇幅说明、配套索引。

存在**多阶段流程**时，按「触发 → 采集 / 取数 → 判定 → 处理 → 输出 → 落库」分阶段画，不要把所有节点塞进一张图。

```mermaid
flowchart TD
    A([开始]) --> B[触发源：[触发方式]]
    B --> C[取数 / 采集]
    C --> D{数据是否就绪}
    D -->|否| E[标记数据不足 / unknown 并记录原因]
    D -->|是| F[执行判定与规则计算]
    F --> G{是否命中}
    G -->|命中| H[生成结果并落库]
    G -->|未命中| I[写正常记录]
    H --> J[输出 / 推送]
    J --> K{输出是否成功}
    K -->|失败| L[降级处理]
    K -->|成功| M([结束])
    E --> M
    I --> M
    L --> M
```
